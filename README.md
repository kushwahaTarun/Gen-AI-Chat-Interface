# Gen-AI Chat Interface

A modern, responsive chat interface built with Next.js for interacting with AI models. This application provides a feature-rich environment for real-time AI conversations with features like speech-to-text, text-to-speech, conversation history, and more.

## 🚀 Quick Start

1. Clone the repository
2. Install dependencies:
```bash
npm install
```
3. Set up your environment variables (see .env.example)
4. Run the development server:
```bash
npm run dev
```

## 🛠 Tech Stack

- Next.js 13+ with App Router
- TypeScript
- Redux Toolkit for state management
- Firebase Authentication
- Tailwind CSS for styling
- Real-time chat capabilities
- Speech-to-Text and Text-to-Speech integration

## 🌟 Key Features

- Real-time AI chat interface
- Speech-to-Text input
- Text-to-Speech output
- Conversation history
- Message export functionality
- User authentication
- Mobile responsive design
- Dark/Light mode support
