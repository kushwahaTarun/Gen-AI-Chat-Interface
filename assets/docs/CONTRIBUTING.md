# Contributing Guidelines

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a new branch
4. Make your changes
5. Submit a pull request

## Development Setup

### Prerequisites
- Node.js 16+
- npm or yarn
- Git

### Installation
```bash
# Clone the repository
git clone https://github.com/your-username/gen-ai-chat-interface.git

# Install dependencies
npm install

# Start development server
npm run dev
```

## Code Style

### TypeScript
- Use strict type checking
- Avoid any type
- Document complex types
- Use interfaces over types

### React
- Functional components
- Custom hooks for logic
- Props interface definition
- Performance optimization

### CSS/Styling
- Tailwind CSS classes
- BEM methodology
- Responsive design
- Dark mode support

## Testing

### Unit Tests
- Jest framework
- Component testing
- Hook testing
- Utility testing

### Integration Tests
- API integration
- User flows
- Error scenarios
- Performance tests

## Pull Request Process

1. Update documentation
2. Add/update tests
3. Follow code style
4. Create detailed PR description
5. Request review

## Commit Guidelines

### Format
```
type(scope): description

[optional body]

[optional footer]
```

### Types
- feat: New feature
- fix: Bug fix
- docs: Documentation
- style: Formatting
- refactor: Code restructure
- test: Testing
- chore: Maintenance

## Code Review

### Review Process
1. Code quality check
2. Test coverage
3. Documentation review
4. Performance impact
5. Security assessment

### Merge Requirements
- Passing tests
- Code review approval
- Documentation updates
- No merge conflicts
